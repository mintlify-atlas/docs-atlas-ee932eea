tarpc decouples the RPC framework from how bytes travel between client and server. Any type that implements both `Stream<Item = io::Result<Item>>` and `Sink<SinkItem, Error = io::Error>` qualifies as a transport. This means you can wrap an existing transport — or build a brand-new one from scratch — without touching any tarpc internals. This guide explains when and how to do that, using the `compression` example as a concrete demonstration.

## What qualifies as a transport

tarpc's `Transport` type alias is defined conceptually as:

```rust filename="type alias (conceptual)"
// A transport is anything that is both:
// - Stream<Item = io::Result<Item>>        (receives deserialized messages)
// - Sink<SinkItem, Error = io::Error>      (sends serialized messages)
```

The built-in `serde_transport::Transport` implements this contract by wrapping a length-delimited byte stream with a `tokio-serde` codec. But nothing stops you from layering additional transformations on top.

## When to use a custom transport

Use a custom transport when you need behaviour that belongs at the byte-stream level rather than in a request hook or handler:

- **Compression / decompression** of message payloads
- **Encryption** beyond what TLS provides (e.g., application-layer envelope encryption)
- **Custom framing** when talking to a non-tarpc peer
- **In-process channels** for testing (tarpc ships `transport::channel` for this purpose)
- **Any `AsyncRead + AsyncWrite` medium** not already covered by the `tcp` or `unix` modules

## The `custom_transport` example — Unix sockets

The `custom_transport` example shows the minimal pattern: bind a `UnixListener`, accept connections, frame each one with `LengthDelimitedCodec`, and hand the result to `serde_transport::new`.

```rust filename="examples/custom_transport.rs"
use tarpc::{
    client, context,
    server::{BaseChannel, Channel},
    serde_transport as transport,
    tokio_serde::formats::Bincode,
    tokio_util::codec::length_delimited::LengthDelimitedCodec,
};
use tokio::net::{UnixListener, UnixStream};

#[tarpc::service]
pub trait PingService {
    async fn ping();
}

#[derive(Clone)]
struct Service;

impl PingService for Service {
    async fn ping(self, _: context::Context) {}
}

#[tokio::main]
async fn main() -> anyhow::Result<()> {
    let bind_addr = "/tmp/tarpc_on_unix_example.sock";
    let _ = std::fs::remove_file(bind_addr);

    let listener = UnixListener::bind(bind_addr).unwrap();
    let codec_builder = LengthDelimitedCodec::builder();

    async fn spawn(fut: impl Future<Output = ()> + Send + 'static) {
        tokio::spawn(fut);
    }

    // Server: accept → frame → serde → serve
    tokio::spawn(async move {
        loop {
            let (conn, _addr) = listener.accept().await.unwrap();
            let framed = codec_builder.new_framed(conn);
            let transport = transport::new(framed, Bincode::default());

            let fut = BaseChannel::with_defaults(transport)
                .execute(Service.serve())
                .for_each(spawn);
            tokio::spawn(fut);
        }
    });

    // Client: connect → frame → serde → call
    let conn = UnixStream::connect(bind_addr).await?;
    let transport = transport::new(codec_builder.new_framed(conn), Bincode::default());
    PingServiceClient::new(client::Config::default(), transport)
        .spawn()
        .ping(tarpc::context::current())
        .await?;

    Ok(())
}
```

The key insight: `serde_transport::new(framed, codec)` is the building block behind `tcp::listen` / `tcp::connect`. You can call it directly with any `AsyncRead + AsyncWrite`.

## The `compression` example — wrapping an existing transport

The `compression` example takes the custom-transport idea further by adding a transparent deflate compression layer *on top of* a `serde_transport::tcp` transport. The `add_compression` function takes any transport and returns a new one:

```rust filename="examples/compression.rs"
use flate2::{Compression, read::DeflateDecoder, write::DeflateEncoder};
use futures::{Sink, SinkExt, Stream, StreamExt, TryStreamExt, prelude::*};
use serde::{Deserialize, Serialize};
use serde_bytes::ByteBuf;
use std::{io, io::Read, io::Write};

/// On-wire envelope that distinguishes compressed from uncompressed messages.
#[derive(Debug, Deserialize, Serialize)]
pub enum CompressedMessage<T> {
    Uncompressed(T),
    Compressed {
        algorithm: CompressionAlgorithm,
        payload: ByteBuf,
    },
}

/// Wraps a transport that speaks `CompressedMessage<T>` and returns one that
/// speaks `T`, transparently compressing outbound messages and decompressing
/// inbound ones.
fn add_compression<In, Out>(
    transport: impl Stream<Item = io::Result<CompressedMessage<In>>>
        + Sink<CompressedMessage<Out>, Error = io::Error>,
) -> impl Stream<Item = io::Result<In>> + Sink<Out, Error = io::Error>
where
    Out: Serialize,
    for<'a> In: Deserialize<'a>,
{
    transport.with(compress).and_then(decompress)
}
```

`Stream::and_then` applies `decompress` to every inbound item; `Sink::with` applies `compress` to every outbound item. Because the result is still a `Stream + Sink`, it satisfies tarpc's transport contract.

### Using the compressed transport

```rust filename="examples/compression.rs (main)"
use tarpc::{client, context, serde_transport::tcp, server::{BaseChannel, Channel},
            tokio_serde::formats::Bincode};

#[tokio::main]
async fn main() -> anyhow::Result<()> {
    let mut incoming = tcp::listen("localhost:0", Bincode::default).await?;
    let addr = incoming.local_addr();

    // Server: wrap the raw transport with compression
    tokio::spawn(async move {
        let transport = incoming.next().await.unwrap().unwrap();
        BaseChannel::with_defaults(add_compression(transport))
            .execute(HelloServer.serve())
            .for_each(spawn)
            .await;
    });

    // Client: wrap the raw transport with compression
    let transport = tcp::connect(addr, Bincode::default).await?;
    let client = WorldClient::new(client::Config::default(), add_compression(transport)).spawn();

    println!("{}", client.hello(context::current(), "friend".into()).await?);
    Ok(())
}
```

Both sides call `add_compression(transport)` with the plain TCP transport; every message is deflate-compressed on the wire without any changes to the service definition or handlers.

## Step-by-step guide to building your own wrapper

<Steps>
  <Step title="Define your wire envelope type">
    Create a `Serialize + Deserialize` enum or struct that represents the on-wire format your wrapper produces:

    ```rust filename="src/transport.rs"
    #[derive(Serialize, Deserialize)]
    pub enum MyEnvelope<T> {
        Plain(T),
        Transformed { /* ... */ },
    }
    ```
  </Step>

  <Step title="Write encode and decode async functions">
    These are the functions passed to `Sink::with` and `Stream::and_then`:

    ```rust filename="src/transport.rs"
    async fn encode<T: Serialize>(msg: T) -> io::Result<MyEnvelope<T>> {
        // transform msg → MyEnvelope
    }

    async fn decode<T: for<'de> Deserialize<'de>>(
        env: MyEnvelope<T>,
    ) -> io::Result<T> {
        // transform MyEnvelope → msg
    }
    ```
  </Step>

  <Step title="Compose with an existing transport">
    ```rust filename="src/transport.rs"
    pub fn wrap_transport<In, Out>(
        inner: impl Stream<Item = io::Result<MyEnvelope<In>>>
               + Sink<MyEnvelope<Out>, Error = io::Error>,
    ) -> impl Stream<Item = io::Result<In>> + Sink<Out, Error = io::Error>
    where
        Out: Serialize,
        for<'a> In: Deserialize<'a>,
    {
        inner.with(encode).and_then(decode)
    }
    ```
  </Step>

  <Step title="Plug it in">
    Pass the wrapped transport to `BaseChannel::with_defaults` on the server or directly to the generated `Client::new` on the client — exactly the same as any other transport.

    ```rust filename="src/main.rs"
    // Server
    let raw = tcp::listen("localhost:0", Bincode::default).await?;
    // ...
    let transport = raw_transport; // from the listener
    BaseChannel::with_defaults(wrap_transport(transport))
        .execute(MyService.serve())
        .for_each(spawn)
        .await;

    // Client
    let transport = tcp::connect(addr, Bincode::default).await?;
    MyServiceClient::new(client::Config::default(), wrap_transport(transport)).spawn();
    ```
  </Step>
</Steps>

## Running the examples

```bash
# Unix-socket custom transport
cargo run --example custom_transport --features "serde-transport"

# Deflate-compressed TCP transport
cargo run --example compression --features "serde-transport,tcp"
```

<Tip>
For unit-testing services without a real network, use the in-process `tarpc::transport::channel::unbounded()` or `::bounded()` channel transport. It implements the same `Stream + Sink` contract and requires no network setup.
</Tip>
