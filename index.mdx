tarpc is an async RPC framework for Rust that lets you define remote procedure call services directly in Rust code — no separate schema language, no `.proto` files, no code-generation step outside of Cargo. Annotate a trait with `#[tarpc::service]` and tarpc generates a fully-typed async client, server scaffolding, and wire protocol handling powered by Tokio.

## Why tarpc?

Most RPC frameworks require you to write a schema in a separate language (`.proto`, `.capnp`, IDL files), run a code generator, and then keep schema and implementation in sync. tarpc takes a different approach: the service definition **is** the Rust trait.

<CardGroup cols={2}>
  <Card title="Schema in Code" icon="code">
    Define your RPC interface as a Rust trait. No separate schema files or compilation steps — your IDE understands everything.
  </Card>
  <Card title="Cascading Cancellation" icon="circle-xmark">
    Dropping a request future automatically notifies the server to cancel the in-flight work and all downstream requests.
  </Card>
  <Card title="Deadline Propagation" icon="clock">
    Deadlines flow automatically through service chains. A 10-second request with 2 seconds of work leaves 8 seconds for downstream calls.
  </Card>
  <Card title="Pluggable Transports" icon="plug">
    Any type implementing `Stream + Sink` can be a transport — TCP, Unix sockets, TLS, compressed channels, or in-memory pipes.
  </Card>
  <Card title="Distributed Tracing" icon="chart-network">
    Built-in OpenTelemetry integration propagates trace contexts across service boundaries automatically.
  </Card>
  <Card title="Serde Serialization" icon="database">
    Enable the `serde1` feature for JSON or Bincode serialization, or skip it entirely for in-process channels with zero overhead.
  </Card>
</CardGroup>

## A taste of tarpc

```rust quickstart.rs
use futures::prelude::*;
use tarpc::{client, context, server::{self, Channel}};

// Define the service interface as a Rust trait
#[tarpc::service]
trait World {
    async fn hello(name: String) -> String;
}

// Implement the generated trait for your server struct
#[derive(Clone)]
struct HelloServer;

impl World for HelloServer {
    async fn hello(self, _: context::Context, name: String) -> String {
        format!("Hello, {name}!")
    }
}
```
